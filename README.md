# Alif Hossen Portfolio

## Project files
- `index.html` - main portfolio and gaming collection
- `education.html` - education page
- `style.css` - responsive styling
- `script.js` - mobile navigation and game-list interactions
- `assets/profile.png` - profile photo
- `assets/logo.svg` - site logo and favicon
- `assets/games/` - locally stored artwork for the 45 game cards

## Run locally
Open `index.html` in a modern browser. Game artwork is loaded from local files in `assets/games/`. Google Fonts and Tailwind are still loaded from their CDNs for the existing typography and styling.

## Game artwork
The game-card image paths in `index.html` are connected to the matching local PNG, JPG, and WebP files. See `assets/games/ASSET-GUIDE.md` for the full filename list and replacement instructions.


Game cards link to their official store or information page. Mobile titles use Google Play where available; PC titles use their official Steam store page or developer website.
