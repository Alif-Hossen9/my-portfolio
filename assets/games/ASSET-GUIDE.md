## Replace an image manually
1. Put the replacement image in this folder.
2. Keep the same filename and extension, or update the matching image `src` in `index.html`.
3. Use a square PNG or WebP app icon where possible. For wide logos, use a transparent PNG and keep `object-fit: contain`.

All game images are local. The game cards do not depend on external image URLs.
